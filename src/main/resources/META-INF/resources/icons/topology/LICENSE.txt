Icons from the ExamPro Kubernetes Architecture Icons set, vendored here. Two modifications
were made to every file:

1. The root <svg> element gained explicit width and height attributes. Without an intrinsic
   size, Chrome falls back to the 300x150 default for a replaced element and Cytoscape, which
   uses that size as the source rectangle when drawing the node background, rendered the icons
   distorted and cropped.
2. The background tile gained a corner radius of roughly 9% of its width, so the icon sits
   inside the rounded topology node without a hard square edge.
